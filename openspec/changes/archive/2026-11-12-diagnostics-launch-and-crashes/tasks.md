The next start logs `app.ended_unexpectedly`. *Status (2026-11-12):* `app/src-tauri/tests/native_crash.rs` is written and type-checks for `x86_64-pc-windows-msvc` with clippy `-D warnings`, but hasn't run on Windows yet.
