<CardGrid>
  <Card title="Host" icon="laptop">
    Start Claude Code, OpenCode, omp, Codex, Grok, pi or a plain terminal in a project folder and share the invite code. Only you type
    into the agent, on your own login.
  </Card>
  <Card title="Watch" icon="open-book">
    Viewers see the terminal and, for Claude Code, a timeline of prompts, answers, tool calls and file diffs. Everyone
    scrolls and searches at their own pace.
  </Card>
  <Card title="Peer to peer" icon="random">
    The session goes straight from host to viewers, encrypted. The sharing service only introduces them and cannot read
    the session.
  </Card>
  <Card title="Your own server" icon="setting">
    Teams can run their own sharing service with Docker Compose or Kubernetes and point SpecDeck at it in Settings.
  </Card>
</CardGrid>
