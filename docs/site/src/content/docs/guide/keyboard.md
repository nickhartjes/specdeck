---
title: Keyboard and screen readers
description: Use SpecDeck with the keyboard alone or with a screen reader.
---

Everything in SpecDeck works with the keyboard alone, and every control has a name that screen readers (VoiceOver, Narrator, Orca) announce. To have them read the terminal too, turn on **Screen reader support** in [Settings](/specdeck/guide/settings/).

| To | Press |
|---|---|
| See all keyboard shortcuts | **⌘/** (macOS) or **F1** (Windows, Linux), or **Help › Keyboard Shortcuts** |
| Move between the toolbar, the terminal and the side panel | **F6**, or **Shift+F6** to go back. In your own terminal, Tab goes to the agent, so F6 is the way out |
| Move on from a viewer's terminal | **Tab**, as anywhere else |
| Start a new line in the agent's prompt, in your own terminal | **Shift+Enter** |
| Switch side-panel tabs | The left and right arrow keys, once a tab has focus |
| Host a session | **⌘N** (macOS) or **Ctrl+Shift+N** (Windows, Linux) |
| Join a session | **⌘J** (macOS) or **Ctrl+Shift+J** (Windows, Linux) |
| Find in the terminal and timeline | **⌘F** (macOS) or **Ctrl+F** (Windows, Linux); **Ctrl+Shift+F** in the host's own terminal |
| Open Timeline, Files or People | **⌘1**, **⌘2**, **⌘3** (macOS) or **Ctrl+1**, **Ctrl+2**, **Ctrl+3** (Windows, Linux) |
| Open Settings | **⌘,** (macOS) or **Ctrl+,** (Windows, Linux) |
| See what the connection is doing | **⇧⌘D** (macOS) or **Ctrl+Shift+D** (Windows, Linux), or **Help › Connection Status** |
| Make everything larger or smaller | **⌘+**, **⌘−**, and **⌘0** for actual size (macOS) or **Ctrl++**, **Ctrl+−**, **Ctrl+0** (Windows, Linux), or **View › Zoom In**, **Zoom Out**, **Actual Size**. The level is remembered |

Zoom changes only your own window. One exception: while you host, zooming in fits fewer columns in your terminal, so the agent's terminal gets narrower for everyone, as it does when you make the window smaller.
